# Code of Conduct

This Code of Conduct applies to the **fidan-actions** repository, its issue
tracker, pull requests, discussions, and related project spaces.

## Our Commitment

The Fidan project aims to foster a respectful, professional, and collaborative
environment for all contributors and community members.

We are committed to providing a welcoming and inclusive experience for everyone
regardless of experience level, background, or identity.

Participants in the Fidan community are expected to treat others with respect
and professionalism.

## Expected Behavior

Contributors and community members should:

- be respectful and constructive in discussions
- focus on improving the project and solving problems
- accept feedback gracefully
- be open to different viewpoints and experiences
- help create a positive and productive environment

## Unacceptable Behavior

The following behaviors are not tolerated in the Fidan community:

- harassment, insults, or personal attacks
- discriminatory or offensive language
- trolling or intentionally disruptive behavior
- publishing private information without permission
- any conduct that creates a hostile or unsafe environment

## Scope

This Code of Conduct applies to all project spaces including:

- GitHub issues
- pull requests
- discussions
- action documentation
- workflow examples
- any official Fidan communication channels related to this repo

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

If unacceptable behavior occurs, maintainers may take appropriate action
including:

- warning the individual
- removing comments or contributions
- temporarily or permanently banning users from the project

Enforcement decisions are made at the discretion of the maintainers.

## Reporting Issues

If you experience or witness unacceptable behavior, please report it privately
or contact the maintainers.

All reports will be reviewed and handled responsibly.

## Acknowledgement

By participating in this project, you agree to abide by this Code of Conduct
and help maintain a respectful and productive community.
